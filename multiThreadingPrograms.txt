if you  submit call Object to executer then after  completeing the

import  java.util.concurrent.*;
class MyCallable implements Callable
{
int num;
MyCallable(int num)
{
this.num=num;
}
public Object call()throw Exception
{
s.o.p(Thread.currentThread().getName()+"sum of numbers::"+num+"numbers::"+);

}
return  sum;
}
}
