What is Next.js?

Next.js is a React framework that provides:

Server Side Rendering (SSR)
Static Site Generation (SSG)
Client Side Rendering (CSR)
File-based Routing
API Routes
Image Optimization
SEO
Authentication Support
Fast Performance
React
   |
   |----> Next.js
              |
              |---- Routing
              |---- SSR
              |---- SSG
              |---- API
              |---- SEO
              |---- Middleware

In Next.js, how you use Welcome.js depends on whether it is a component or a page.

Case 1: Welcome.js is a Component (Most Common)
Project Structure
my-next-app
│
├── app
│     └── page.js
│
├── components
│     └── Welcome.js
components/Welcome.js
export default function Welcome() {
    return (
        <h2>Welcome Component</h2>
    );
}
app/page.js
import Welcome from "../components/Welcome";

export default function Home() {
    return (
        <div>
            <h1>Home Page</h1>

            <Welcome />
        </div>
    );
}
Output
Home Page

Welcome Component
Case 2: Welcome.js is Inside the app Folder (App Router)

In the App Router, the file must be named page.js to become a route.

Folder Structure
app
│
├── page.js
│
└── welcome
      └── page.js
app/welcome/page.js
export default function Welcome() {
    return (
        <h1>Welcome Page</h1>
    );
}

Visit:

http://localhost:3000/welcome

No import is needed because Next.js creates the route automatically.

Case 3: You Have Welcome.js in the app Folder

Suppose you have:

app
│
├── page.js
└── Welcome.js

This will not become a route automatically.

You can import it like a normal React component.

app/Welcome.js
export default function Welcome() {
    return (
        <h2>Welcome Component</h2>
    );
}
app/page.js
import Welcome from "./Welcome";

export default function Home() {
    return (
        <div>
            <Welcome />
        </div>
    );
}
Case 4: Navigate to the Welcome Page

If app/welcome/page.js exists:

import Link from "next/link";

export default function Home() {
    return (
        <div>
            <Link href="/welcome">
                Go to Welcome Page
            </Link>
        </div>
    );
}
Case 5: Using a Button to Navigate
"use client";

import { useRouter } from "next/navigation";

export default function Home() {
    const router = useRouter();

    return (
        <button onClick={() => router.push("/welcome")}>
            Go to Welcome
        </button>
    );
}
Summary
If Welcome.js is...	How to use it
components/Welcome.js	import Welcome from "../components/Welcome"; then <Welcome />
app/Welcome.js	import Welcome from "./Welcome"; then <Welcome />
app/welcome/page.js	Visit /welcome or use <Link href="/welcome">
pages/welcome.js (Pages Router)	Visit /welcome automatically
Which Next.js router are you using?
App Router (app/ folder, Next.js 13+)
Pages Router (pages/ folder, older style)

The import and routing approach is slightly different depending on which one you're using.

"use client";

import { useState, useEffect } from "react";

export default function Home() {

    const [users, setUsers] = useState([]);

    useEffect(() => {

        fetch("https://jsonplaceholder.typicode.com/users")
            .then(res => res.json())
            .then(data => setUsers(data));

    }, []);

    return (

        <div>

            {
                users.map(user => (
                    <p key={user.id}>
                        {user.name}
                    </p>
