SQL-SUBQUERY
================
Subquery is also called  as NestedQuery or inner Query
A  Subquery  is  a query that is  used  in  a Clause of another
Query

Subquery  is used  to dynamically build a search 
condition for  the main query
A  single query may be  made up of  mutiple subqueries

A  where  clause  of one query may contain another
query  called   a  subquery

subquery  can also  be used within the  having  clause

Oracle  process subqueries  before  the main query

A  subquery  may contains another subquery

subquereis may  contain join queries  and search 
conditions  of their own

a subquery can  refer to  tables in main query

a subquery  can return  single  or multiple values

Subquery  that  returns a  single  value
(1 row of 1 column only)

we can use single row  Relational operators
we  can  also  use multi-row  Relational operators

subquery it should be return more  than one  table

subquery to refers  multiple  tables

SubQUERY-InlineView
===================
A  Query  used  in select clause or  from 
clause or group by  clause  or order by clause  or any other
clauses  of SQL except in WHERE clause  and having clause

SubQuery-Correlated SubQuery
==========================
A  correlated subquery  is a subquery,which is  executed
repeatedly  ,once  for  each  row of the main query

A  correlated subquery is a  nested query 
which is executed once for each  'candidate row'
seleted by the main

display all cmployees who earn  salaries greater
than  the  average  salary with in  their own department

Subquery-Precautions
===================
Subqueries are  include in where or  having clause of
main query  only

we should choose proper relational Operator based on
 the output of subquery

if a subquery produces no values the  main query will not
produce  any  output
use  DISTINCT  in some  cases to  force subquery to  
generate a  single  value

use  aggregate functions without  a group by clause to  
generate a  single  value

you can use subqueries  that  produce any  number of 
rows  if you use multi-Row relational operators

Subquery | Nested Query | Inner Query

Query inside  another query

Main Query(Sub query)

Subqueries are placed  in where Clause or Having clause
only

subquery will  execute before the main query

subquery will execute only once for the entire main query

steps:
        1.execution of subquery
        2.subquery   gives a result
        3.using  the  result of subquery by main query
         4.execution of main query  using the result of  sub
query
5.producing  final output by main  query 
Types:
==========
-->scalar subquery
-->single row subquery : 
-->single value subquery:a subquery  that  returns exactly one value
of one column only

A subQuery  that  Returns more  than one value
