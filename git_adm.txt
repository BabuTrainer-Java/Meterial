What is git pull?

git pull is used to:

Download latest code from remote repository
Merge it into your local branch

It combines:

git fetch + git merge

git pull origin main


Pull All Remote Branch Updates

git pull --all

Pull Using Rebase

Instead of merge:

git pull --rebase origin main
